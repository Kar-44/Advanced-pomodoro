# Advanced Pomodoro Timer

Pomorodo timer is not something you need to reinvent, it pretty much reached it's peak. However you can always modify it and add new features. This simple set of timers allows
you to set your own times for each phase and pick the amount of total cycles before you take a long break.

### Purpose

Pomodoro timers have been scientifically proven to be a good way to manage work and study flow to maximize the efficiency. After learning a bit about 'learning' I decided to
also add a Recall phase which is supposed to let you focus on only retrieving information from last Study phase. I hope this concise setup will allow the user to completely 
focus on what's important and enter efficient workflow.

### Functions

Simple timer where you set your own times for each phase, if you set Recall = 0 then that phase is skipped, as it's 
not very useful for some subjects. The 'Zen mode' (eye icon) makes the timer blurred and stops the animations making
it not distracting if you use a second screen to display it, while still being easily accessible. You can Skip a phase while still contributing to the cycle, and Reset a phase in case someone distracts you and you don't pause.

Have fun!
